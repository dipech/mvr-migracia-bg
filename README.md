# Очередь в миграцию

Мобильная SPA для отслеживания талонов Миграции в Софии. Русскоязычный интерфейс, сканирование QR камерой или с фотографии, собственный прогноз и история окон.

## Запуск

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Относительные пути и hash-навигация поддерживают GitHub Pages в подкаталоге. Исходный код находится в `main`, опубликованная сборка — в `gh-pages`. В настройках GitHub Pages выберите Deploy from a branch → gh-pages → / (root).

Для обновления сайта после сохранения изменений в Git выполните `npm run deploy`. Команда запускает тесты и сборку, затем обновляет ветку `gh-pages` без принудительной перезаписи истории. Нужны права записи в репозиторий `origin`.

## Использование

Добавьте талон через QR, фото или ссылку исходного сайта. Несколько талонов отслеживаются одновременно. Кнопка «Демонстрационный режим» открывает пример с вымышленными данными без запросов к Миграции и без сохранения.

Рядом с вашим номером отображается максимальный текущий номер той же серии в подходящих окнах. Номера могут повторяться в течение дня; записи сопоставляются по ticket_id. Окна продолжают обновляться после завершения собственного талона, пока есть действующий QR текущего дня. При ошибках обновления на экране остаются последние полученные данные. Фоновый опрос не показывает индикаторы загрузки и сообщения об ошибках; время последнего успешного обновления видно в постоянной строке. При противоречиях между API окна и талона показывается «Данные уточняются».

Все талоны и наблюдения хранятся в localStorage устройства. История окон и прогнозов очищается при смене дня по Europe/Sofia; собственные талоны и последний статус сохраняются. Для удаления всех сохранений доступна кнопка «Сбросить приложение».

Опрос каждые 5 секунд выполняется, пока браузер позволяет странице работать. При блокировке iPhone или переключении приложения Safari может остановить опрос. PWA не устраняет это ограничение. Можно включить удержание экрана, сообщения и звук; звуку после нового открытия может потребоваться повторное разрешение нажатием кнопки. Системные уведомления зависят от поддержки браузера; серверного push нет.

## Прогноз

Официальная оценка воспроизводит алгоритм страницы Миграции. Собственная сортирует ожидающие талоны по времени выдачи, учитывает пересечение услуг и доступных окон, историю вызовов, завершений и неявок. 300 сценариев дают медиану и диапазон 10–90%. При недостатке данных используются длительности источника с соответствующей пометкой. Приоритеты вызова неизвестны; диапазон не является гарантией. Точность оценивается после фактического вызова по сохранённым прогнозам.

История основана на данных API и наблюдениях браузера. Пропуски и повторные вызовы помечаются как приблизительные. Чужие QR-коды не сохраняются.

## Проверки

Автоматические тесты покрывают нормализацию, расчёт очереди, прогноз, пороги, историю, смену дня и ошибки хранилища. Проверка камеры, звука, Wake Lock и системных разрешений на настоящем iPhone остаётся ручной.
